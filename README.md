# Undergraduate Projects｜大學課程與研究作品

**繁體中文** | [English](./README.en.md)

本儲存庫收錄 10 份大學課程報告、提案或簡報，另有 1 份課程作業說明與 1 份學士論文。主題涵蓋交通與基礎設施、建築與測量、水利防災，以及資料分析。所有作品均以 PDF 提供；部分課程成果為分組完成。

## 課程成果

### 交通運輸與基礎設施

- [2021 年太魯閣號出軌事故個案研究](./2021%20Taroko%20Express%20Derailment%20Case%20Study.pdf) — 軌道運輸學分組期末報告。整理事故經過與調查資料，以故障樹分析致因，並討論施工區管制與安全防護。
- [台 2 線 68K 邊坡工程地質特徵化](./Highway_2_Km68_Slope_Characterization.pdf) — 工程地質及應用期末報告。分析崩塌區的岩層、構造與人為擾動，評估既有防護工程，提出補強與監測建議。
- [校園人行橋設計「橋鳥」](./Pedestrian_Bridge_Design.pdf) —「土概 02」分組期末提案簡報。結合校園通行、生態棲地與夜間照明需求，並依構件與載重測試調整橋梁設計。

### 建築、施工與測量

- [臺大學生宿舍新建工程規劃](./Construction%20Planning%20for%20a%20New%20Student%20Residence%20Hall%20at%20National%20Taiwan%20University.pdf) — 營管分組期末報告。提出宿舍設計與施工方案，涵蓋工序、進度、成本與現金流分析，以及價值工程；內容為課程提案。
- [測量實習成果報告](./Surveying%20Fieldwork%20Final%20Report.pdf) — 111 學年度第 1 學期測量實習分組報告。彙整校園建物與地形測繪、外業觀測、內業計算及成果圖。

### 水文、水利與防災

- [臺大校園都市化前後的逕流分析](./Before-and-After%20Analysis%20of%20Urbanization%20Impacts%20on%20NTU%20campus.pdf) — 水文相關課程的期中作業，PDF 未載正式課名。以莫拉克颱風降雨為案例，使用曲線數法估算土地利用改變前後的有效降雨與直接逕流。
- [HEC-RAS 河道水躍模擬](./Hydraulic%20Engineering%20Final%20Report%20%E2%80%93%20River%20Channel%20Simulation%20Using%20HEC-RAS.pdf) — 水利工程分組期末報告。建立河道模型，調整曼寧粗糙係數與斷面間距，並比較模擬與參考研究的水躍位置。
- [強降雨與颱風下的臺北市避難所選擇](./Analysis%20and%20Research%20on%20Optimal%20Shelter%20Selection%20in%20Taipei%20City%20under%20Heavy%20Rainfall%20and%20Typhoon%20Conditions.pdf) — 道路路網與空間分析相關期末專案，PDF 未載正式課名。整合路網、避難收容處所與降雨風險，分析避難路線、可達性及交通韌性。

### 資料分析與工程經濟

- [背景驗證系統的人機行為辨識](./Evaluating%20the%20Ability%20of%20Background%20Verification%20Systems%20to%20Distinguish%20Human%20and%20Automated%20Behavior.pdf) — 機器學習相關研究，PDF 未載正式課名。蒐集人類與腳本操作資料，訓練二元分類模型，分析行為特徵及誤判案例。
- [台積電財務報表分析](./Engineering%20Economics%20Final%20Report-Financial%20Statement%20Analysis.pdf) — 工程經濟學期末專案。分析台積電及其子公司的財務結構、償債能力、經營能力與獲利能力。

## 學士論文

- [Modern Roundabout Safety in Motorcycle-Dominated Environment](./Undergraduate%20Thesis%20-%20Modern%20Roundabout%20Safety.pdf) — 國立臺灣大學學士論文。以分期處置的雙重差分方法，評估傳統圓環改建為現代圓環後，在機車使用比例高的交通環境中的事故安全效果。

## 課程作業說明

- [土木館增建 BIM 設計題目](./Civil%20Engineering%20Building%20Expansion%20%E2%80%93%20BIM%20Design%20Project.pdf) — 國立臺灣大學工程圖學（Engineering Graphics，CIE 1005）於 2022 年秋季學期提供的徵求提案書，說明土木館整修與增建的 BIM 設計要求。此 PDF 是**作業題目**，不是完成的學生作品。
